## 採用済みの前提

- 天井は十分に高く、移動・回転・傾斜時にも搬入物が接触しないものとする。天井の寸法確定や衝突判定は行わない。
- 搬入物は段ボールで梱包された、変形しない直方体とする。入力は梱包後の外寸とする。
- 安全マージンは梱包後の外寸に追加する。
- 荷物中心を玄関枠外側面から1m手前に置いて開始し、玄関へ入る初期区間の中心後退を禁止する。外部空地の寸法確定ではなく、現行の仮定外床内で箱全体を検証する開始仕様とする。
- 対象はメゾネットタイプの賃貸の「玄関 → 階段 → 2階廊下 → LDK入口」の一方向の固定経路。LDK入口をゴールとし、LDK内部の再現は行わない。利用者による経路寸法・形状の編集、経路選択、逆方向の搬出は設けない。
- 階段を上がって2階に到達後は右に曲がり、その先をまっすぐ進むとLDK入口へつながる。左右に扉なしの条件と、終端のLDK枠・固定開放扉は維持する。寸法と図面・写真の実登録は未確認のままとする。
- 利用者の入力は梱包外寸と各面の安全マージン。必要な回転・傾斜は計算側が探索する。この対象と方向は利用者指定であり、画像から寸法や終了姿勢を確定した事実とは区別する。
- 手すり、巾木、ドアノブなど、モデル化しない要素はルートの [AGENTS.md](../AGENTS.md) に従う。

## 資料から確認できる事実

- 推定寸法付き間取り図には「推定寸法」「1帖=1.62m²として算出」とあり、図面の比率による概算である旨が記載されている。
- 間取り図の階段折り返し部分には、扇形・三角形状の踏面を示す線がある。階段写真にも折り返し部分の回り段が写っている。
- 階段写真には、木製の笠木が付いた中央の腰壁と、外側の壁に沿った手すりが写っている。
- 玄関から階段を見た写真には、土間から室内床への段差と、階段手前の水平な床が写っている。
- 玄関ドア写真には長さの基準となる実測値がなく、ドアの有効開口寸法は読み取れない。

## 図面に記載された推定寸法

| 項目               | 記載値        | 状態・留意点                                         |
| ------------------ | ------------- | ---------------------------------------------------- |
| 階段の通行幅       | 約780 mm      | 推定値。手すりなどの突出を差し引いた有効幅かは未確認 |
| 折り返し部分の内幅 | 約1600 mm     | 推定値。寸法の基準面や中央の腰壁との位置関係は未確認 |
| 折り返し部の奥行き | 約750〜800 mm | 推定値。平らな踊り場の奥行きとしては扱わない         |

上表は画像に記載された値の転記であり、実測・再計算したものではない。
内法・壁芯などの測定基準は資料だけでは確定できない。
750〜800 mmという幅も、実測に基づく誤差範囲を保証するものではない。

## モデル化への判断

- 図面と写真を合わせると、折り返しを回り段のある階段としてモデル化するのが妥当。具体的な段数・踏面形状・高さは未確定とする。
- 中央の腰壁は壁として衝突モデルに含める。外側の手すりを対象外とする方針を、腰壁まで省略する根拠にしない。
- 中央の腰壁は高さを持つ立体として扱う。写真から笠木の高さや幅を数値で確定しない。
- 玄関直後の水平な床と、階段途中の折り返し部分を区別する。
- 写真は形状の確認に用いる。遠近や撮影方向が異なるため、画素数から長さを直接算出したり、図面と写真の左右をそのまま対応させたりしない。
- 暫定モデルに仮定寸法を使う場合は、各値の出典・仮定・未確認状態を記録する。

## 仮定モデルへの採用

`maisonette-assumed-v3` は玄関外・開口・土間・框・下側5直段・6回り段・上側5直段・2階到着床・右折後の直線廊下・LDK枠を一つの座標へ配置する。階段の採用値は通行幅770 mm×2＋中央壁110 mm、回り部奥行775 mm、各蹴上げ170 mm×17、階高2890 mmとする。2階の到着床と廊下の平面は幅770 mm・総長2310 mmを保持し、LDK入口は有効幅720 mm・高さ2005 mmで、いずれも未実測の仮定である。推定図の780/1600/750〜800 mmを上書きした実測値ではない。

中央腰壁と張り出した笠木、玄関/LDKの上枠と固定開放扉、玄関収納の閉鎖扉を物理形状へ含める。2階左右の他室扉は生成せず、連続した側壁とする。段鼻は突出なし、腰壁天端は段状近似、玄関外は有限の矩形という仮定を記録する。新廊下と交差する階段外側壁の人工延長は、その区間だけ上階床下面で止め、上階床そのものは衝突対象として保持する。玄関の要素`solid-entry-jamb-left`（世界X=[−1.385,−.385] m、玄関内向き+Zを見た右側）は上階床と重ならないため、人工延長の上端を14.250 mとする。登録の左右、実際の段数・階高・廊下の実寸・開口・扉の固定状態は未確認のままとする。

LDK側には物理床を作らず、箱全体の枠通過だけを評価する有限の仮想受け領域を使う。LDK室内の移動・旋回・設置や障害物は評価しない。モデル版、全採用値と出典ID、実施した形状試験・小箱の連続検証は[現行の採用値](housing-model-spec.md#現行モデルの採用値)、製品への接続と使用方法は[README](../README.md)を参照する。

## 未確認事項

| 項目                                                         | モデル化への影響                               |
| ------------------------------------------------------------ | ---------------------------------------------- |
| 各段の高さ・奥行き、段数、階高                               | 階段床の高さと傾斜中の衝突判定に必要           |
| 回り段の平面形状と各段の高さ                                 | 折り返し中の移動・回転の検証に必要             |
| 中央の腰壁の厚み・高さ・端部位置                             | 物体の角や下端との衝突判定に必要               |
| 壁間寸法と手すりなどの突出寸法                               | 図面上の通行幅と実際の有効幅の対応に必要       |
| 玄関ドアの有効開口、開放時の扉位置、土間と室内床の寸法・段差 | 玄関を判定区間に含める場合に必要               |
| 2階の階段出口・廊下・LDK入口の開口寸法                       | 固定経路をLDK入口の通過まで評価するために必要  |
| 玄関側の開始領域・LDK入口の通過平面と姿勢条件                | 箱全体の到達と連続した移動を検証するために必要 |

現段階の資料は、住宅の配置と階段の特徴を把握するために利用できる。実住宅を再現する一意の3D寸法データは揃っておらず、仮定を用いたモデルの結果として評価する必要がある。
