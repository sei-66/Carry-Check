# CarryCheck

家具・家電の梱包後の寸法から、特定住宅の搬入経路を通れるか検討する Web アプリです。梱包した荷物を変形しない直方体として扱い、安全マージンを加えた箱の回転・傾斜と連続移動をブラウザ内で検証します。

**「玄関 → 階段 → 2階で右折 → 直線廊下 → LDK入口」の固定経路を、実測前の仮定住宅モデルで検討できます。** LDK入口を箱全体が通過するまでが対象で、室内の移動・設置は評価しません。

## 利用できる機能と制約

- 梱包後の幅・奥行・高さと各面の安全マージンを mm で入力し、「経路を探す」で計算します。外寸は各1〜5000 mm、マージンは各面5〜100 mmです。
- Worker が姿勢を探索し、衝突・床所属・持上げ・床接続を連続検証した経路を3Dで再生します。探索・最終再検証・すき間評価の時間上限は15秒、探索ノード上限は5000です。
- 結果には経路の確認状況を表示し、経路を確認できた場合は計算時間と梱包箱の最小すき間の区間を表示します。すき間評価が終わらない場合は未完了と表示します。未発見・予算上限は搬入不可の証明ではありません。
- 確認した経路は常に表示します。安全マージンは計算へ適用し、3Dの枠は表示しません。結果で入力寸法や条件を再表示・展開する機能はありません。
- デザインはB「ポップ」とD「ソリッド」、表示テーマはライト・ダーク・自動を選べます。初回はソリッドで、外観を切り替えても入力・結果・視点・再生位置を保持します。
- PCとスマートフォンを想定しています。3Dはドラッグで回転、ホイール・ピンチで拡縮でき、ページのスクロールは3D領域の外で行います。

住宅モデルは `maisonette-assumed-v3`、仮定セットは `A-MAISONETTE-2026-10-07-v3` です。**住宅寸法の実測は0件**で、図面・写真の特徴と利用者指定を仮定寸法で結んでいます。天井、作業員の空間、養生材、手すり、巾木、ドアノブ、梱包材の変形、製品ごとの搬送姿勢制限などは評価しません。計算結果は実際の搬入可否を保証しません。

現行モデルと玄関1m手前の開始条件による12サイズの既存検証では、全12件が正常終了し、8件で経路とすき間を確認しました。残る4件は検証上限による未確認です。これは試料ごとの記録であり、家具・家電一般の成立を示しません。住宅の実寸、iOS Safari・Android Chromeの実機操作と性能、実際のPages配信などは未確認です。[検証の範囲と残課題](docs/verification.md)を参照してください。

## 起動

Node.js 24系（24.22.1以上）とnpm 11系を使用します。

```sh
npm ci
npm run dev
```

Windowsでも上記のnpmコマンドで起動します。`scripts/start-local.bat` は任意のローカル補助スクリプトで、Git管理対象外のため新規cloneには含まれません。手元にある場合の操作と保存形式は[開発ガイド](docs/development.md#セットアップ)を参照してください。

```sh
npm run check
npm run build -- --base=/Carry-Check/
```

`check` はLint・整形・テスト・型検査・ビルドを実行します。Pages用ビルドは `dist/` へ出力します。GitHub Actionsでは依存監査・ワークフロー・履歴のシークレット検査も実行し、全検査に合格したmainの成果物だけを配信できます。配信はリポジトリ変数 `PAGES_ENABLED=true` による有効化が必要です。

公開時は非公開のままpushしてCI成功を確認し、住宅画像・秘密情報・ローカル検証資材がコード・履歴・配信物へ入っていないことを確認してから、このリポジトリだけをパブリックへ切り替えます。その後Pagesと配信変数を設定し、初回の手動配信を行います。[CIとGitHub Pages](docs/development.md#ci-と-github-pages)に設定と公開条件をまとめています。
