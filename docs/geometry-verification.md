# 幾何・Worker診断の検証

[目次](README.md) · [計算仕様](calculation.md) · [開発・実行手順](development.md#m1回り段worker計測) · [全体の検証範囲](verification.md)

本書は、住宅から独立したM1局所fixture、距離の解析回帰、Rapier比較診断と専用Workerの証拠をまとめる。製品は独立f64の幾何区間で判定し、Rapier/WASMは診断専用とする。局所fixtureの合格は住宅実寸・玄関からLDK入口までの成立・実搬入・実機性能の合格を意味しない。

## 局所fixtureの定義

実装は[turn-fixture.ts](../src/dev/fixtures/turn-fixture.ts)、追加の解析プローブは[distance-probes.ts](../src/dev/fixtures/distance-probes.ts)。Node回帰とM1専用Workerが共用し、製品Workerや表示専用廊下とは接続しない。

以下は**数値計測・幾何回帰用に作成した仮定**であり、当該住宅の回り段の段数・形状・寸法ではない。全住宅を数値化せずに、回り段、中央腰壁、段高の不連続、連続遷移を検証するための独立した小形状である。ID接頭辞は `fixture-m0-turn-v1`、採用状態は `検証fixture専用`。将来の実住宅寸法へコピーしない。

4つの回り段を90度の2倍の折返しへ配置し、各45度の領域を区切る。局所XZ座標の外側は幅1.600 m・奥行0.800 m、中央の壁は幅0.100 mで、左右の直段幅は0.750 mとなる。これは幾何的に整合する検証値であり、S2の約780 mmと一致させた住宅復元ではない。

| 仮定ID         | 値                                                       | 選択理由                                                     |
| -------------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| F-OUTER        | X=−0.800〜0.800、Z=−0.250〜0.800 m                       | 折返しと前後の1踏面を含む局所領域                            |
| F-OUTER-HEIGHT | Y=−0.200〜2.000 m                                        | M1で追加した局所人工外周の高さ。住宅の物理天井ではない       |
| F-WAIST        | X=−0.050〜0.050、Z=−0.250〜0.050 m、Y=−0.200〜1.200 m    | 高さのある中央壁と閉じた端部を独立照会できる                 |
| F-RISE         | 各0.180 m、5回の上昇で計0.900 m                          | 段ごとの高さ差と総和を解析できる                             |
| F-BOTTOM       | 全床立体の底面Y=−0.200 m                                 | 厚い固体を生成し、上面だけの交差判定にしない                 |
| F-LIFT         | 各領域の仮想持上げ上限0.600 m                            | 高さ差0.180 mをまたぎつつ旧床上限が効く回帰を作る            |
| F-BOX          | 梱包箱0.100×0.100×0.100 m、マージン各面0.010 m           | 接触と十分離れた状態を手計算できる小さい基準箱               |
| F-TERMINAL     | 終端規則を別の局所開口fixtureで試す場合の通過しろ0.001 m | 仮の正の通過しろ。住宅の数値誤差採用値を決めたことにはしない |

以下の頂点は `(X,Z)`、上面高と底面高はY。多角形の頂点は表の順番で閉じる。P1〜P4はそれぞれ凸四角形であり、そのまま凸多角柱にできる。隣接する多角形の内部は重ならず、表の共有辺だけが重なる。

| 床ID | 区分       | 頂点列（m）                                        | 上面高（m） | 次領域との共有辺（m）      |
| ---- | ---------- | -------------------------------------------------- | ----------- | -------------------------- |
| F0   | 下側の直段 | (−.800,−.250), (−.050,−.250), (−.050,0), (−.800,0) | 0.000       | (−.800,0)〜(−.050,0)       |
| P1   | 回り段1    | (−.800,0), (−.050,0), (−.050,.050), (−.800,.800)   | 0.180       | (−.050,.050)〜(−.800,.800) |
| P2   | 回り段2    | (−.800,.800), (−.050,.050), (0,.050), (0,.800)     | 0.360       | (0,.050)〜(0,.800)         |
| P3   | 回り段3    | (0,.800), (0,.050), (.050,.050), (.800,.800)       | 0.540       | (.050,.050)〜(.800,.800)   |
| P4   | 回り段4    | (.800,.800), (.050,.050), (.050,0), (.800,0)       | 0.720       | (.050,0)〜(.800,0)         |
| F5   | 上側の直段 | (.050,−.250), (.800,−.250), (.800,0), (.050,0)     | 0.900       | 終端。F0への隣接なし       |

平面の接続は `F0 → P1 → P2 → P3 → P4 → F5`。Xが負の側から回り段へ入り、Xが正の側から戻る検証用の向きであり、住宅写真への左右登録とは関係しない。下図は形状の接続を示す模式図で、寸法の正本は上表とする。

```text
                  Z=+.800
       (−.800,.800)────(0,.800)────(.800,.800)
             ╲    P2   │   P3    ╱
              ╲        │        ╱
          P1   ╲───────┴───────╱   P4
                中央壁の先端 Z=.050
  Z=0  ─────────┤             ├─────────
            F0 │   中央壁    │ F5
  Z=−.250 ─────┴─────────────┴─────────
        X=−.800 −.050        .050     .800

  経路に沿う断面の上面高（m）                 F5
  .900                                 ┌──────
  .720                           ┌─ P4 ─┘
  .540                    ┌─ P3 ─┘
  .360             ┌─ P2 ─┘
  .180      ┌─ P1 ─┘
  .000 F0 ──┘
  各立体の底面は −.200。段間を斜面で補間しない。
```

検証用の段境界規則は幅0の共有辺を使い、許可領域を膨らませる重なり帯は作らない。F-BOXの各面マージン.010 mを下限へ含めると、F0/P1の境界での梱包箱最下点の許可区間は `[0.190, 0.600]` m、P1/P2では `[0.370, 0.780]` m、P2/P3では `[0.550, 0.960]` m、P3/P4では `[0.730, 1.140]` m、P4/F5では `[0.910, 1.320]` m。回転後のマージン箱の衝突判定はこの条件に加えて行い、区間下端だから通過可能とはしない。

F-BOXを無回転、中心Y=.350 mとしたとき、梱包箱最下点は.300 m、マージン箱最下点は.290 m。中心XZが `(−.400,−.020)` から `(−.400,.020)` へ動く区間はF0/P1境界を横断し、F0の持上げ.300 mとP1の持上げ.120 mをともに満たす。高い踏面との鉛直すき間は梱包箱.120 m、マージン箱.110 mであり、数値照会の独立な正解として使える。

同じ境界で梱包箱最下点を.700 mとした候補は、P1だけなら持上げ.520 mで上限内だが、F0の上限.600 mを越えるため拒否する。旧床を先に外す実装を検出するケースである。F0とF5の間にはポータルがないため、中央壁を越えられる高さへ置いても中心投影が壁を横断する近道は拒否する。

### 比較診断を判定から分ける根拠

Rapier 0.21.0は、解析上.1 mm離れた傾斜箱/P1について、照会予測範囲1 m以内でも`null`を返した。独立f64の投影下限と点対上限から得る区間は約`[−.150,.350] mm`で、`unverified`である。これを衝突とも通過とも断定しない。`null`を予測範囲に基づく正の下限へ置換する方式は住宅用に採用しない。

高さ1 µm・奥行10 µmの三角柱はraw凸形状factoryが形状を返さない。独立区間は解析距離1 mmを含み、診断では`rapierUnavailableSolidIds`へ記録して続行する。未実行、raw形状未生成、照会例外、不一致なしを区別する。

既存の合成直方体回帰では、表面BVHの交差だけで完全包含を検出できず、表面距離が正になることを確認した。Rapierの小寸法照会は相対座標・1000倍の照会スケールを使い、原点付近と±15 m、1 mm〜5 m、平行/対角の接触と距離を解析回帰した。これらも一般凸形状の誤差上限の証明ではない。BVHは比較用devDependencyで、製品Workerへ含めない。

関連テストは[住宅幾何](../tests/housing-geometry.test.ts)、[距離](../tests/prism-distance.test.ts)、[連続距離](../tests/prism-motion-distance.test.ts)、[数値誤差](../tests/numerical-error.test.ts)、[診断](../tests/rapier-diagnostic.test.ts)、[ライブラリ比較](../tests/library-comparison.test.ts)と[テスト方針](../tests/README.md)を参照する。

### 中止・期限・再生成

- 1500 msの初期化遅延、300 msの計算前保持、中止後の同Worker再試行が両URLで成功した。遅延・保持試料は性能値から除外した。ページの中止で生成1/終了1、`cancelled`と`failure.phase: engine-init`を確認した。
- 短期限検査を含む専用検証は通常/サブパスとも`passed`、生成35/終了35。起動・初期化・計算の100 ms、世代寿命1200 msで強制終了し、各回新Workerの通常設定で完了した。寿命検査は初期化/計算完了後のidle到達を確認した。終了済み要求への遅いcancel、初期化/計算中止後の同Worker再試行も成功した。
- 通常期限は通信起動20秒・初期化30秒・M1計算15秒・世代寿命70秒。短期限は`deadlineChecks`に別記録し、標準期限の境界・遅延応答/エラー・同時期限・古い世代・寿命時刻固定はFake clockの回帰で確認した。製品の計算期限は要求上限＋1秒であり、M1専用値と混同しない。
- 通常/サブパスのDOM観測記録は`cache/m1-deadlines-root-observed.json`と`cache/m1-deadlines-pages-observed.json`。警告・エラーログは空だった。

生成/終了数は常駐メモリの測定ではない。同期CPU計算中の協調中止や中断遅延の計測でもない。20/30/15/70秒をそのまま待つ実Worker試験と、JSONボタンの保存先確認は未実施である。

## 残る採用条件

| 未確認事項       | 次に必要な証拠                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 一般形状の誤差   | 住宅で許す寸法・辺長・座標・姿勢の数値誤差根拠。±.25 mmを一般保証へ格上げしない                |
| Rapier不一致     | .1 mm不一致の原因と固定raw API更新時の解析回帰。診断失敗を製品の結果へ転用しない               |
| 実機・冷間ロード | iOS Safari/Android Chromeの初回と後続5回。キャッシュを制御しない新規Workerを完全冷間と扱わない |
| 資源・中止       | 実メモリ/GPU保持量、同期CPU中の中断遅延                                                        |
| 保存・期限       | JSONダウンロードの保存完了、標準期限への実Worker到達試験                                       |
| 実住宅           | 実寸、資料の登録、扉姿勢、仮想制約の現地照合。住宅台帳を正本とする                             |

仮定住宅の製品機能はこの局所検証と別に接続・検証されている。上記の未確認を、製品が未実装という説明へ置き換えない。実施済みの製品範囲と公開条件は[検証資料](verification.md)で管理する。
