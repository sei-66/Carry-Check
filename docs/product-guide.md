# 操作ガイド

[目次](README.md) · [住宅モデル](../references/housing-model-spec.md) · [検証資料](verification.md)

## 対象と前提

「玄関 → 階段 → 2階で右折 → 左右に扉のない直線廊下 → LDK入口」の一方向の固定経路を調べます。終端のLDK枠・固定開放扉を含め、マージン箱全体がLDK側の枠端を越えるまでが対象です。LDK内の移動・旋回・姿勢復元・設置、逆方向の搬出、経路の選択・編集は扱いません。

現行は `maisonette-assumed-v3` / `A-MAISONETTE-2026-10-07-v3` の仮定住宅です。住宅実測は0件で、採用寸法と未確認事項は[住宅台帳](../references/housing-model-spec.md)に記載しています。天井、手すり、巾木、ドアノブ、作業員の空間、養生材、梱包の変形、製品ごとの傾斜制限・指定搬送姿勢は計算に含みません。中央腰壁・笠木・床・蹴上げは衝突対象です。持上げ上限は計算上の仮想制約です。

## 入力と計算

1. 梱包後の**幅・奥行・高さ**を mm で入力します。各辺は1〜5000 mm、安全マージンは各面5〜100 mmで、小数を使用できます。外寸の初期欄は空、安全マージンの初期値は各面10 mmです。外寸に梱包材を含め、その外側へマージンを追加します。
2. 「経路を探す」を実行します。必要な回転・傾斜・横移動・持上げは計算側が探索します。計算の完了・失敗・中止後は「経路と、荷物の動き」の3D欄へフォーカスと表示位置を移します。計算結果はその下で確認できます。動作確認用の入力には120×180×140 mm・各面10 mmを使えます。例を選ぶ機能はありません。
3. 計算中はフォームまたは結果欄で中止できます。入力を変更すると実行中の計算と旧結果・旧経路を無効にします。計算中に入力欄でEnterを押しても再送信しません。

荷物中心は玄関枠の外側面から1m手前で開始し、玄関へ入る初期区間では中心を後退させません。全マージン箱が有限の開始領域と枠外側に収まる姿勢を探します。階段などの後続区間では必要な後退も候補にします。未計算時の箱表示は開始位置の説明であり、通過確認済みの姿勢ではありません。

製品の時間上限は探索・最終再検証・すき間評価を合わせて15秒、ノード上限5000、幾何照会上限50000です。Workerの準備・通信はこの計算時間と区別します。候補と予算は有限なので、同条件の再試行で経路が見つかるとは限りません。

## 結果の読み方

| 表示・状態                                                 | 意味と対応                                                                                                           |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 仮定モデル上の経路を確認                                   | 全移動区間の再検証が成立した姿勢列です。実際の搬入の保証ではありません。計算時間・最小すき間と再生操作を確認できます |
| 最小すき間の評価が未完了                                   | 経路は確認できても、経路全体の距離評価が予算内に終わらない場合があります。未評価を0 mmや十分な余裕とは扱いません     |
| 探索条件内では経路未発見                                   | 開始・終端候補不成立、ノード・時間・連続検証の上限などの理由を確認し、入力を見直します。搬入不可の証明ではありません |
| 計算を中止しました                                         | 入力は保持されます。再計算できます                                                                                   |
| 入力・モデルを確認してください／計算を完了できませんでした | 計算失敗です。表示された理由を確認し、修正・再試行します。解消しない場合は再読み込みします                           |
| 住宅モデルを利用できませんでした                           | 計算できない状態です。経路未発見や通過成功とは区別します                                                             |

主表示のすき間は、**マージンを加える前の梱包箱表面と物理障害物の、経路全体にわたる最小距離の区間**です。床・壁・枠・扉・腰壁・笠木を含みます。人工外周・床所属・持上げ上限・仮想受け領域は含みません。区間を狭めないよう外向きに丸めて表示します。仮定寸法の誤差まで保証する数値ではありません。

結果欄には計算時間と最小すき間の区間を表示し、すき間定義の長文は表示しません。評価未完了の場合はその説明を表示します。入力寸法は入力欄で確認し、結果欄には寸法の再表示や計算条件を展開する操作を設けていません。

## 3Dと再生

- 三角の再生ボタンで確認した経路を再生し、再生中は一時停止アイコンで停止します。ボタンの右隣の「経路上の表示位置」スライダーで姿勢を確認し、その右に表示位置の割合を表示します。末尾からは初めから再生できます。再生速度は作業時間を表しません。
- 経路は常に表示し、安全マージンの3D枠と表示切替は設けません。入力したマージンは計算へ適用します。
- ドラッグで回転、ホイール・ピンチで拡縮します。操作開始ボタンはなく、3D領域では常に操作できます。ページのスクロールは領域の外で行います。「斜め」「正面」「上から」、拡大・縮小・視点リセットも利用できます。
- 初期・視点プリセット・リセットは、住宅全体を捉える基準距離に倍率0.82を適用します。画面サイズや外観の切替では現在の拡大率を保持します。
- 外壁の一部を内部が見えるよう切り欠いて表示します。衝突判定は元の共通形状を使います。画面上で見えない壁を通過できるという意味ではありません。
- 3Dは表示領域の近くまでスクロールすると準備します。一度生成した表示はスクロールや外観切替で作り直しません。WebGL 2が使えない場合は表示失敗と再試行を案内し、入力・計算・文字の結果を利用できます。
- 動きを減らす設定では再生を停止し、静止位置の指定を使えます。タブが非表示になると再生は停止し、復帰時に自動再開しません。

## 外観

画面上部の「デザイン」で「ポップ」か「ソリッド」を、「表示テーマ」でライト・ダーク・自動を選びます。初回はソリッド・自動です。自動はOSの明暗設定に追従します。

デザインと表示テーマだけをブラウザへ保存します。保存できない環境でもその画面では切り替えられます。切替では入力・エラー・実行中の計算・結果・視点・再生位置を保持します。入力や計算結果を再読み込み後に復元する機能はありません。

確認手順と実機で残る条件は[検証資料](verification.md)、開発専用の表示・計測画面は[開発ガイド](development.md)を参照してください。
