## 正本と証拠の読み方

- 利用者向けの現行仕様は操作ガイド、住宅の座標・採用値・未確認寸法は住宅台帳、実施済みの確認と残課題は検証資料を正本とします。実装値の根拠となるコード・設定・テストへ各文書から辿れます。
- `観察`・`推定`・`仮定`・`実測`を区別します。住宅実測は0件です。解析fixture、仮定住宅の経路、実住宅での搬入はそれぞれ別の証拠です。
- 測定の日時・モデル版・開始条件・ハッシュ・試行数は試料の識別情報です。旧条件の測定を現行条件の実績や一般的な性能保証へ流用しません。
- 実行時の住宅・試料定義は `src/model/`・`src/dev/`、Node専用fixtureは `tests/fixtures/`、設定は `config/` にあります。製品は `dist/`、専用ビルドは `cache/verification-dist/`・`cache/performance-dist/`、監査記録と生のJSON・ログ・画像などの補助検証記録は非追跡の `cache/` へ保存します。詳しい出力先と保存条件は[開発ガイド](development.md)を参照してください。住宅の元画像は非追跡の `references/` に置き、配信物に含めません。
- 文書の命名、履歴、監査記録の管理は[ドキュメント管理のルール](../AGENTS.md#ドキュメント管理)に従います。公開に必要な現行の残課題は[検証資料の受け入れ条件](verification.md#未確認事項と受け入れ条件)を参照してください。
